Panduan Penulisan NFC Chip

Agar kartu fisik (kartu PVC, stiker NFC, atau cincin pintar) bisa dibuka saat di-tap ke HP klien, ikuti langkah mudah berikut:

1
Salin URL Halaman Ini Salin tautan atau domain tempat Anda meng-host halaman web kartu nama digital ini.
2
Download Aplikasi NFC Tools Unduh aplikasi NFC Tools melalui Google Play Store (Android) atau Apple App Store (iOS).
3
Tulis (Write) ke Tag NFC Buka aplikasi NFC Tools > Pilih menu Write > Add a record > Pilih URL / URI > Tempel (Paste) link web Anda > Klik Write lalu dekatkan chip NFC ke bagian belakang HP Anda.
